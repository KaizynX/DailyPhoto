# DailyPhoto 操作手册

## 启动与退出

双击 `app\DailyPhoto.exe` 启动程序。启动成功后，Windows 任务栏右侧的通知区域会出现蓝色相机图标；如果图标被折叠，请点击通知区域的向上箭头查看。

关闭拍照窗口不会退出 DailyPhoto。需要彻底退出时，右键托盘图标并选择“退出”。

## 拍摄照片

程序启动或屏幕解锁时，如果当天没有照片，拍摄窗口会自动出现。当天成功保存后，后续解锁不会重复触发。也可以双击托盘图标，或右键图标选择“立即拍照”。

拍摄窗口默认显示在当前屏幕的中上方，并与屏幕上沿保留安全距离，让视线更接近屏幕上沿的摄像头且不会遮掉标题栏。

1. 摄像头打开后开始倒计时。
2. 倒计时结束时程序冻结当前画面。
3. 选择“保存”保留照片，或选择“重拍”重新倒计时。
4. 如果没有操作，程序会在“自动保存等待”结束后保存。

照片成功保存后拍摄窗口自动关闭，托盘程序继续运行。默认文件位置为：

```text
photos\YYYY\MM\YYYY-MM-DD_HH-mm-ss.jpg
```

## 参数设置

右键托盘图标并选择“参数设置…”。

- `照片保存目录`：可输入相对路径或绝对路径。相对路径以 DailyPhoto 项目目录为基准。
- `拍照倒计时`：打开摄像头后等待多少秒取帧，允许 0–3600 秒。
- `自动保存等待`：拍摄后等待确认的时间，允许 0–3600 秒。
- `摄像头编号`：默认摄像头通常为 0；有多个摄像头时可尝试 1、2 等编号。
- `JPEG 质量`：允许 1–100；数值越高，画质和文件体积通常越大。
- `镜像预览和照片`：开启后，保存结果与镜子中的方向一致。

点击“保存”后，新设置写入项目根目录的 `config.json`，并在下一次打开拍摄窗口时生效。

## 开机自启动

右键托盘图标，点击“开机自启动”即可切换；菜单项前有勾时表示已启用。该设置只影响当前 Windows 用户。

启用后，程序会在登录时常驻托盘，并注册一个无运行时限的解锁恢复任务。如果托盘进程意外退出，下次解锁会重新启动程序；当天已经拍过时仍然不会重复拍摄。

也可以运行：

- `install.ps1`：启用登录自启动；
- `uninstall.ps1`：关闭登录自启动，不会删除程序、设置或照片。

## 生成人脸对齐延时影像

右键通知区域的 DailyPhoto 图标，选择“生成延时影像…”。生成窗口提供：

- `完整头部与环境（16:9）`：缩小人脸并增加头顶留白，同时保留肩部、座椅和更多原图环境，默认选项；
- `人脸特写（正方形）`：接近原先仅显示头部的紧凑画面；
- MP4 和 GIF 独立复选框，可以只生成一种或同时生成；
- 每帧时长；
- 是否在左下角显示照片的拍摄日期。

点击“开始生成”后会在后台处理；窗口会显示当前进度，完成后可以直接打开输出目录。

也可以在项目目录中运行命令行工作流：

```powershell
.\create-timelapse.ps1
```

默认读取 `config.json` 指定的照片目录，按文件名顺序处理 DailyPhoto 标准命名的照片，生成带日期的 800×450 宽景 MP4，并输出：

```text
generated\
  daily-photo.mp4
  aligned\YYYY\MM\*.jpg
  manifest.json
```

原始照片不会被裁剪、覆盖或移动。`manifest.json` 会列出每张照片是否成功；没有检测到人脸的照片默认跳过。

常用选项：

```powershell
# 同时生成 MP4 和 GIF
.\create-timelapse.ps1 --format both

# 只生成 GIF
.\create-timelapse.ps1 --format gif

# 生成人脸特写且不显示日期
.\create-timelapse.ps1 --crop face --timestamp none

# 显示完整拍摄日期和时间
.\create-timelapse.ps1 --timestamp datetime

# 每帧停留 500 毫秒，输出宽度 960 像素
.\create-timelapse.ps1 --duration 500 --size 960

# 包含名称不符合 DailyPhoto 规则的导入图片
.\create-timelapse.ps1 --include-all

# 任何一张检测失败都停止生成
.\create-timelapse.ps1 --strict
```

`--format` 可取 `mp4`、`gif` 或 `both`；`--crop` 可取 `wide` 或 `face`；`--timestamp` 可取 `date`、`datetime` 或 `none`。MP4 通常体积更小、颜色更好；GIF 便于直接嵌入聊天和网页。重复运行会更新 `generated` 中的派生文件，但不会影响原图。

## 常见问题

### 找不到托盘图标

先展开 Windows 通知区域的隐藏图标。如果仍不存在，重新运行 `app\DailyPhoto.exe`。程序只允许一个实例，重复启动不会出现多个图标。

### 无法打开摄像头

关闭会议、直播、相机等可能占用摄像头的软件，并检查 Windows 是否允许桌面应用访问摄像头。然后从托盘菜单选择“立即拍照”。

### 使用了错误的摄像头

在“参数设置…”中依次尝试摄像头编号 0、1、2。修改后关闭当前拍摄窗口，再重新选择“立即拍照”。

### 照片保存失败

确认保存目录存在或可以创建，并且当前用户具有写入权限。可以使用托盘菜单的“打开照片目录”检查当前位置。

### 查看诊断信息

项目根目录的 `daily_photo.log` 会记录启动、摄像头打开、拍摄、保存和程序异常。日志自动轮换，且不包含照片内容。

## 手动测试与构建

运行以下命令可忽略“今天已经拍摄”的判断并立即打开拍摄窗口：

```powershell
app\DailyPhoto.exe --force
```

开发环境中使用 PowerShell 7 运行 `build.ps1` 可重新生成 `app\DailyPhoto.exe` 和 `app\DailyPhotoTimelapse.exe`。
